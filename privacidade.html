Política de privacidade do Jarvis

Atualizada em 23 de outubro de 2026.

Quem usa

O Jarvis é um assistente pessoal de uso privado, operado e usado por uma única pessoa, que é também a dona da conta Google conectada. Ele não é oferecido a terceiros.

Quais dados acessa

Com a autorização expressa do usuário, o Jarvis acessa pela API do Google apenas os dados da conta conectada que forem necessários para as tarefas pedidas: eventos da agenda, tarefas, arquivos do Drive, documentos, planilhas, apresentações e envio de e-mails.

Como usa

Os dados são usados somente para executar o que o próprio usuário pede, como criar um evento, organizar um arquivo ou enviar um e-mail aprovado por ele. Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou usado para treinar modelos de inteligência artificial.

Onde ficam

As credenciais de acesso ficam em um servidor privado do usuário, protegidas e acessíveis apenas a ele. O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.

Uso de dados das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
